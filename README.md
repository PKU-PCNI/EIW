# EIW
# Overview

This work introduces Embodied Intelligent Wireless (EIW), an AI-native wireless communication paradigm empowered by Synesthesia of Machines (SoM).

This repository is reserved for materials related to the EIW research. Code and datasets are not currently available.

# Citation

X. Cheng et al., "Embodied Intelligent Wireless (EIW): Synesthesia of Machines Empowered Wireless Communications," IEEE Wireless Communications, 2026.
